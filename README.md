# 스파게티

3D 프린터로 탑을 쌓는 세로 화면 리듬 게임. 노즐이 **정박마다 아래 층 한가운데에서 잠깐 멎는다.**
그 순간에 압출해야 층이 제자리에 얹히고, 박자를 놓치면 아예 압출되지 않는다.
거기에 노즐 온도까지 같이 맞춰야 한다. 결국엔 무너진다.

## 하는 법 (맥)

```sh
./run.sh
```

시작 화면에서 **시작 / 언어 / 컬렉션 / 끝내기** 를 위아래로 고른다. 한국어와 영어를 지원하고,
고른 언어는 `lang.txt` 에 남아 다음에도 그대로 뜬다.

| 키 | 하는 일 |
|---|---|
| 스페이스 / 클릭 | 박자에 맞춰 압출 |
| W 또는 위 화살표 | 노즐 가열 |
| R | 처음부터 |
| ESC | 메뉴 열기 / 닫기 (**조작법은 여기에만 있다** — 화면에 상시로 띄우지 않는다) |
| 위아래 / 엔터 | 메뉴에서 고르기 |
| ESC > 컬렉션 | 지금까지 만든 실패작 보기 |
| 좌우 | 메뉴에서 값 바꾸기 (화면 효과) |
| Q | 메뉴에서 끝내기 |

## 박자

노즐은 한 박에 좌우를 한 번 왕복하되, **정박에서 아래 층 한가운데에 와서 속도가 거의 0이 된다.**
그래서 박자를 맞추는 것과 위치를 맞추는 것이 같은 일이 된다.

| 판정 | 어긋난 정도 | 결과 |
|---|---|---|
| **정타** | 0.10박 이내 | 기계가 제자리에 찍는다. 폭 손실 0, 콤보 +1, 음이 한 단계 올라간다 |
| **보통** | 0.22박 이내 | 노즐이 있던 자리에 그대로 얹힌다. 어긋난 만큼 깎이고 콤보가 끊긴다 |
| **엇박** | 그 밖 | **압출되지 않는다.** 층도 안 늘고 콤보만 끊긴다 |

한 박에 한 층만 나간다. 연타해도 소용없다.
BPM은 100에서 시작해 한 층마다 1.2씩 올라 180에서 멈춘다.

박자를 크게 놓쳐도 바로 죽지는 않는다 — 압출이 거부될 뿐이다.
죽는 건 보통 판정이 쌓여 폭이 다 깎이거나, 온도를 놓쳐 탑이 무너질 때다.

## 규칙

- 층은 아래 층과 **겹치는 부분만** 남는다. 벗어난 쪽은 떨어진다. 한 번 좁아진 폭은 돌아오지 않는다
- 노즐 온도는 계속 떨어진다. 층이 쌓일수록 더 빨리 식는다
  - **200~220도** 정상
  - **220도 위** 늘어짐 — 층이 납작해져서 높이가 안 오르고 마찰이 줄어 미끄러진다
  - **200도 아래** 접착 불량 — 얹는 순간 옆으로 틀어지고 회전이 먹는다
- 쌓인 층은 전부 물리 객체라 무게중심이 벗어나면 **진짜로 무너진다**
- 끝나는 조건: 탑이 기울어 무너짐 / 쓰러짐 / 완전히 빗나감.
  **결과창에 사유는 안 쓴다** — 터지는 걸 봤으면 안다. 숫자만 남긴다

## 소리

효과음 파일은 없다. 전부 `src/audio.lua`에서 사인파·톱니파·잡음을 샘플 단위로 합성한다.

| 소리 | 언제 |
|---|---|
| 압출음 | 정타로 얹을 때. **연속 정타마다 음이 한 단계씩 올라가고**, 끊기면 처음 음으로 돌아간다. 보통 판정은 낮고 둔한 소리 |
| 메트로놈 | 정박마다. 네 박에 한 번은 낮고 크게 짚는다 |
| 거부음 | 엇박으로 눌러 압출이 안 될 때 |
| 잘리는 소리 | 아래 층을 벗어난 부분이 떨어져 나갈 때. 많이 잘릴수록 크고 높다 |
| 붕괴음 | 탑이 무너지거나 완전히 빗나갔을 때 |
| 경고음 | 노즐 온도가 적정 구간을 막 벗어난 순간, 한 번만 |

`--shot` 으로 띄우면 마스터 볼륨을 0으로 두고 돌기 때문에 검증할 때는 조용하다.

## 피드백 (juice)

`game-feel` 스킬의 트라우마 모델을 따른다. 이벤트가 트라우마(0~1)를 **더하고**, 초당 1.3씩
빠지며, 실제 흔들림은 `트라우마²`이라 작은 일은 거의 안 흔들리고 큰 일만 세게 친다.
흔들리는 건 그리는 것뿐이고 물리 바디는 건드리지 않는다.

| 이벤트 | 등급 | 트라우마 | 히트스톱 | 그 밖 |
|---|---|---|---|---|
| 정타 | small | 0.14 | 없음 | 층이 눌렸다 되튐, 흰 플래시, 불똥 4개 |
| 5연속마다 | medium | 0.35 | 없음 | 불똥 10개, "N연속" 팝 |
| 보통 | small | 0.10 | 없음 | 약하게 눌림, 불똥 2개 |
| 엇박 | - | 0 | 없음 | 노즐만 부르르 떤다 |
| 잘림 | small | 0.06~0.16 | 없음 | 불똥 3개 |
| 붕괴 | large | **1.0** | **0.18초** | 폭발 (아래 참고) |

**히트스톱은 붕괴에만 넣었다.** 스킬은 피드백을 핵심 시뮬레이션에 걸지 말라고 하는데,
리듬 게임에서 시간을 멈추면 박자 시계가 통째로 밀려서 플레이어가 박자를 놓친다.
붕괴 순간은 이미 박자가 끝난 뒤라 거기서만 안전하다.

움직임은 전부 이징을 탄다 — 층이 얹힐 때와 판정 글씨는 `easeOutBack`(1을 살짝 넘었다 돌아옴),
나머지는 감속. 선형 보간은 쓰지 않는다.

ESC 메뉴의 **화면 효과**로 흔들림과 플래시를 강하게 / 약하게 / 끔 중에 고를 수 있다.

## 박자 표시

어디서 쳐야 하는지를 화면이 네 군데에서 동시에 말해 준다. 전부 같은 색 규칙을 쓴다 —
**회색이면 아직, 주황이면 보통, 초록이면 지금.**

- **노즐에서 흘러나오는 필라멘트** — 늘 쭉 나오면서 처진다. 정박에 노즐이 멎으면 뭉치고,
  반박에 빨라지면 길게 늘어난다 (연출이고 판정과는 무관)
- **갠트리 바** — 화면에서 제일 넓은 요소. 정박이 가까울수록 물들고 두꺼워진다
- **좁혀 들어오는 고리** — 노즐 둘레를 돌며 작아진다. 가운데 고정 과녁과 겹치는 순간이 정타
- **아래 층 폭 표시** — 꼭대기 층 양 끝의 세로 눈금. 이 안에 들어와야 안 깎인다
- **박자 점 네 개** — 마디 안에서 지금 몇 번째 박인지. 첫 박이 크다

## 실패작 컬렉션

끝나면 방금 만든 게 **이름과 처분을 달고 보관함에 들어간다.** 몇 층까지 갔는지로 정해진다.

| 층 | 이름 | 처분 |
|---|---|---|
| ~2 | 덩어리 | 폐기 |
| ~5 | 코스터 | 폐기 |
| ~9 | 문 괴임돌 | 재활용함 |
| ~14 | 연필꽂이 | 재활용함 |
| ~20 | 화분 | 서랍행 |
| ~27 | 사탑 | 서랍행 |
| ~35 | 탑 | 책상 위 |
| ~45 | 첨탑 | 책상 위 |
| 46~ | 작품 | 전시 |

터지기 직전 모양(층마다 위치·폭·각도·색)을 떠서 같이 저장하기 때문에, 보관함에는
**그때 그 망한 모양 그대로** 작게 그려진다. ESC 메뉴 > 컬렉션 에서 본다.
저장은 `collection.txt` 한 줄에 한 점, 최대 60점.

## 끝날 때

탑이 그냥 쓰러지지 않는다. **0.18초 멎었다가 통째로 터진다.**

층마다 좌우로 흩뿌리는 충격량과 제각각의 회전을 먹이고, 층 색 그대로 불똥을 튀기고,
중심에서 흰 불똥 40개와 충격파 고리 두 개가 퍼진다. 화면은 트라우마 1.0 으로 가장 세게 흔들리고
흰 플래시가 한 번 터진다.

탑이 세로로 길어서 "중심에서 바깥으로" 미는 보통 방식을 쓰면 기둥이 위아래로 늘어나기만 한다.
그래서 좌우는 따로 흩뿌리고, 위로 뜨는 힘만 중심에 가까울수록 세게 준다.

결과창은 **1.1초 뒤에** 떠오른다. 터지는 걸 먼저 보라고.
점수와 높이는 터지기 직전 값으로 박아 둔다 — 안 그러면 날아간 꼭대기 층 위치로 높이를 재서
26층짜리가 407mm 로 찍힌다.

## 화면 크기

기준 해상도 **450x800** 을 정해 두고, 창 크기에 맞춰 통째로 스케일한다(`src/screen.lua`).
비율이 안 맞으면 남는 쪽을 어두운 테두리로 채운다. 그래서 창을 아무렇게나 늘여도 레이아웃이
안 깨지고, UI 를 절대 좌표로 찍어도 된다.

시작할 때 바탕화면 높이를 보고 기준 비율을 지키는 가장 큰 창을 잡는다. 이게 없으면
세로 800 이 안 들어가는 화면에서 **아래쪽 HUD 가 화면 밖으로 잘린다** — 실제로 이 맥에서
창이 450x751 로 줄어 있었다.

## 맥용 만들기

```sh
./build_mac.sh
```

LÖVE 앱 껍데기를 복사해 `Contents/Resources/` 에 `game.love` 를 넣고, 이름·아이콘·번들 ID 를
바꾼 뒤 ad-hoc 서명한다. `.love` 파일을 가로채지 않게 문서 타입 선언은 뺀다.
결과는 `dist/Spaghetti.app` 과 `dist/Spaghetti.dmg` (12MB).

dmg 를 열면 Spaghetti.app 과 `/Applications` 바로가기가 같이 있다. 끌어다 넣고 실행하면 된다.
**다만 공증(notarize)은 안 돼 있다.** 이 맥에서 만든 거라 여기서는 그냥 열리지만,
남한테 보내면 받는 쪽에서 Gatekeeper 에 막힌다 (우클릭 > 열기 로 넘길 수 있다).

## 윈도우용 만들기

```sh
./build_win.sh
```

LÖVE 11.5 윈도우 런타임을 받아서 `love.exe` 뒤에 `game.love` 를 이어 붙인다. 윈도우 실행 파일
형식(PE)은 뒤에 데이터가 더 붙어 있어도 되고, LÖVE 는 자기 실행 파일 뒤를 zip 으로 읽는다.
결과는 `dist/spaghetti-win64.zip` (6.3MB). 압축 풀고 `Spaghetti.exe` 를 누르면 된다 —
dll 들이 같은 폴더에 있어야 한다.

**exe 아이콘은 LÖVE 기본 그대로다.** 바꾸려면 윈도우에서 rcedit 한 줄이면 된다:

```
rcedit Spaghetti.exe --set-icon icon.ico
```

`icon.ico` 는 묶음 안에 같이 넣어 뒀다. 맥에는 rcedit(이나 wine)이 없어서 여기서는 못 바꾼다.
창 안의 아이콘은 `love.window.setIcon` 으로 이미 바뀌어 있다.

## 저장 위치

| 어떻게 돌리는가 | 저장 폴더 |
|---|---|
| 소스에서 (`./run.sh`) | `~/Library/Application Support/LOVE/spaghetti/` |
| 묶은 빌드 (.app / .exe) | `~/Library/Application Support/spaghetti/` |

LÖVE 는 게임이 실행 파일에 붙어 있으면(fused) 저장 경로에서 `LOVE/` 를 뺀다.
그래서 **소스로 돌릴 때와 빌드로 돌릴 때 컬렉션이 따로 쌓인다.** 일부러 합치지 않았다 —
개발하면서 쌓인 실패작이 배포본에 섞이는 게 더 이상하다.

## 글자

화면에 나오는 모든 글자는 `src/lang.lua` 한 곳에 있다. 코드에는 한글을 직접 쓰지 않는다.
컬렉션은 이름을 글자가 아니라 **번호로 저장**한다 — 글자로 저장하면 언어를 바꿨을 때
옛날 기록만 다른 언어로 남는다. 예전 형식으로 저장된 줄은 층수를 보고 다시 매긴다.

## 한글 입력기

입력은 키 이름이 아니라 **scancode(물리적 키 위치)** 로 받고, `love.keyboard.setTextInput(false)`
로 글자 입력을 꺼 둔다. 안 그러면 한글 입력기가 켜져 있을 때 키가 입력기에 먹혀서
영문 상태에서만 조작된다.

## 구조

```
main.lua          love 콜백, 입력, 스크린샷 모드
src/game.lua      박자 시계, 판정, 층 쌓기, 온도, 물리, 붕괴
src/draw.lua      화면 그리기 전담
src/audio.lua     효과음 합성 (파일 없이 코드로)
src/juice.lua     화면 흔들림, 히트스톱, 파티클, 플래시, 이징
src/screen.lua    기준 해상도 스케일링
src/menu.lua      ESC 메뉴 항목과 이동
src/collection.lua 실패작 보관함 (저장·불러오기·등급)
src/lang.lua      한국어/영어 문자열
tools/make_icon.py 아이콘을 코드로 그린다 (icon.png, icon.icns, icon.ico)
build_win.sh      윈도우용 묶음 만들기
build_mac.sh      맥용 .app 과 .dmg 만들기
assets/fonts/     Pretendard (한글)
```

물리는 LÖVE에 내장된 Box2D(`love.physics`)를 그대로 쓴다. 층 하나가 동적 바디 하나고,
무너지는 건 따로 짠 게 아니라 물리 엔진이 알아서 하는 것.

## 만든 환경

LÖVE 11.5. brew cask `love`는 2026-09-01에 macOS Gatekeeper 검사를 통과하지 못해 비활성화됐다.
그래서 [공식 릴리스](https://github.com/love2d/love/releases)의 `love-11.5-macos.zip`을 직접 받아
`~/Applications/love.app`에 두고 격리 속성을 지운 뒤 ad-hoc 서명해서 쓴다. `run.sh`가 그 경로를 부른다.

## 렌더링 확인

```sh
~/Applications/love.app/Contents/MacOS/love . --shot
```

박자를 ±0.12박 흘리는 사람이 친다고 보고 자동으로 쌓다가, 쌓는 중 화면, 정박에 딱 맞은 순간,
메뉴, 폭발 2장, 끝난 화면, 창을 880x620 으로 늘였을 때의 화면을 PNG로 남기고 종료한다.
저장 위치는 `~/Library/Application Support/LOVE/spaghetti/`.
